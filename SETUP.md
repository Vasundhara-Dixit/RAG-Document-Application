# Setting this up on your GitHub profile

## What's static and what's live
- **Static** (built once, only rebuilt when you change the design or your photo): the banner,
  the lanyard badge, the toolkit/fields/heading graphics, the connect buttons, the footer.
  Rebuild them with `python scripts/build_static_assets.py`.
- **Live** (refreshed automatically by GitHub Actions): the GitHub Statistics, Contribution
  Graph and Languages cards, the Featured Projects section, and the contribution
  snake (generated by `scripts/snake.py` from your real contribution calendar — no extra branch or third-party action). You never run these by hand — the workflows in `.github/workflows/` do it for you.

## 1. Create the repository
This kind of README only renders on your profile if it lives in a repository named
**exactly** your username: `Vasundhara-Dixit/Vasundhara-Dixit`, and that repository is public.
If you haven't already, create it on GitHub, then push everything in this folder to its
`main` branch.

## 2. Turn on write access for Actions
The workflow commits back to the repo (it updates `README.md`, the live cards and the snake), so it needs write permission:
**Settings → Actions → General → Workflow permissions → "Read and write permissions" → Save.**

## 3. Featured Projects (automatic)
Every **public** repository you own is picked up automatically (newest activity first, up to `max_projects`)
and shown with its real language, star count and a one-sentence description built only from real data. The
profile repo itself, forks and archived repos are skipped.

To hide a project, do any one of these (it comes back when you undo it):
- add its name under `hidden:` in `featured.yml`
- add the GitHub topic `hide-from-profile` to the repo (repo page -> gear next to "About" -> Topics)
- make the repo private

To pin or reorder, list names under `featured:` (they always come first); see the comments in `featured.yml`.

## 4. Let it run
- **Update profile** runs every hour, and also right away whenever you push a change to
  `featured.yml`, `README.template.md`, or the generator scripts. You can also trigger it
  manually from the **Actions** tab → *Update profile* → *Run workflow*.

If your account is still new (no followers, no stars, one contribution), so the cards
will look correspondingly quiet — that's expected, not a bug, and they'll fill in as you use
GitHub. Nothing is padded with fake numbers.

## Changing the design later
1. Edit `scripts/banner.py`, `scripts/lanyard.py`, `scripts/intro.py` or `scripts/static_parts.py`.
2. Replace `assets/source/portrait.png` if you want a different photo.
3. Run `python scripts/build_static_assets.py` and commit the regenerated files in `assets/`.

## Files at a glance
```
README.template.md      edit THIS (not README.md) for wording/layout — README.md is generated
featured.yml             your featured-repo allowlist
scripts/
  common.py              shared theme constants
  banner.py               the animated hero banner (dark + light)
  lanyard.py              the swinging ID badge with the QR code (dark + light palettes)
  intro.py                the Introduction scene (text card + ID badge, dark/light) and the Interests cards
  static_parts.py         headings, toolkit, fields, buttons, footer
  cards.py                 the 3 live stat cards (stats/langs/activity); edit PINNED_SKILLS for the language chips
  snake.py                 the animated contribution snake (dark + light)
  generate_profile.py      pulls real GitHub data and renders README.md + the live cards
  build_static_assets.py   (re)builds everything static — run only on a design change
assets/                  all artwork; assets/generated/ is rewritten by the Action
.github/workflows/
  update-profile.yml       refreshes the live cards, snake and README every hour
```
